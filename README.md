# 상담 예약 (학부모용)

학부모 전용 공개 예약 사이트입니다. 기본 주소로 접속하면 바로 예약 페이지가 열립니다.
내부 관리 기능(일정 생성/삭제/취소)은 포함되어 있지 않습니다 — 빈 시간 조회와 예약만 가능합니다.

## 같은 캘린더 공유
내부 관리 사이트와 동일한 Google 서비스 계정/캘린더를 사용하도록
아래 3개 환경변수를 이 프로젝트에도 똑같이 설정해야 합니다.
- GOOGLE_CLIENT_EMAIL
- GOOGLE_PRIVATE_KEY
- GOOGLE_CALENDAR_ID

학부모가 예약하면 같은 캘린더에 기록되어 내부 관리 사이트에도 그대로 반영됩니다.
